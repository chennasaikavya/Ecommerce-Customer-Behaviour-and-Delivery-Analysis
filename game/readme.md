
# Alien Invasion: Data Detective Run

A browser-based educational game built using HTML, CSS, JavaScript, and Canvas.

## How to Run the Game

1. Open the project in Visual Studio Code.
2. Open the `game` folder.
3. Open `index.html`.
4. Right-click inside the HTML file.
5. Select **Open with Live Server**.

## Game Controls

- Left / Right Arrow: Move between lanes
- Up Arrow / Space: Jump
- Down Arrow: Slide
- E / Shift: Activate skate mode

## Technologies Used

- HTML
- CSS
- JavaScript
- Canvas API

## Note

This is a standalone browser game. It currently uses simulated retail data and does not directly load the Olist CSV files.
